- Fecha de ejecución: **pendiente**
- Entorno: Visual Studio Code + terminal de PowerShell (**previsto**)
- Versión de OpenCode (`opencode --version`): **pendiente de observar**
- Modelo e identificador exacto (según interfaz): **pendiente de observar**
- Proveedor: **pendiente de observar**
- Función: implementación asistida, revisión y pruebas (**previsto**)

- Instrucciones versionadas: [`../AGENTS.md`](../AGENTS.md); confirmar carga real en sesión.
- Contexto que se suministrará: consigna, especificación, inventario, archivos del proyecto.
- Contexto que se excluye: secretos, credenciales, datos reales de estudiantes y chats privados.
- Herramientas/permisos realmente utilizados: **pendiente**
- Aprobaciones solicitadas y aplicadas: **pendiente**
- Adaptación comprobable: regla específica de turnos consecutivos en `AGENTS.md`; **evidencia de aplicación pendiente**.
- Configuración externa (si se usa): **pendiente; transcribir extractos saneados y cómo se aplicaron**.

No confundir el plan con evidencia de una ejecución real.
